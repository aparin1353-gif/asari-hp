## Part -1. この設計の前提を疑う

v2の最大の欠陥は、**参照記事の前提が浅利俊介に当てはまるかを検証せず、丸ごと適用したこと**だった。

### -1-1. 記事はどこまで転用できるか

記事の前提は「**北米・SWE・現地就職・自分から大量応募・ビザの時間制限あり**」。
あなたの前提は「**外資日本法人／日系エンタメ・日本在住・応募せずスカウト待ち・時間制限なし**」。
**能動 vs 受動**という点でも別の土俵である。

| 記事の主張 | あなたへの転用 |
|---|---|
| レジュメ＝サムネ・広告。取捨選択と装飾 | ✅ **完全に転用可。** 市場を問わない普遍原則 |
| ATSと10秒の人間、二正面 | ⚠️ **半分だけ。応募しないのでATSは介在しない。**「10秒の人間」だけが残る |
| 謙遜を捨てる／表彰は前に出す | ✅ 転用可。日本人の過小申告はどの市場でも損 |
| コネ・リファラルを最大限使う | ✅ **むしろ日本の方が効く。** 早稲田のOBOG網は強い |
| 募集要項とのマッチが知名度に勝る | ✅ 転用可。ただし §-1-2 の通り、そのマッチが今は弱い |
| リクルーター／エージェントは使えない | ❌ **真逆。** 受け身モデルではリクルーターが唯一の経路。エージェント面談は市場情報の生命線（§4-2） |
| 1募集に100〜1,000応募 | ❌ 無関係。応募しないので競争率の前提そのものが不要 |
| 返信率10%が目標、5%以下は要改善 | ❌ **廃止。** 応募しないので分母が存在しない。KPIはスカウト受信数へ（§4-1） |
| フィードバックは基本来ない | ⚠️ **受け身モデルではさらに来ない。** エージェント面談で意図的に取りに行く必要がある |
| 1枚のレジュメPDF | ⚠️ 応募しないので即時には不要。ただし**スカウトに返信した瞬間に要求される**ので待機させておく（Part 1） |

**結論:** マインドセット（Part 0）は全面的に採用。**運用ルール（応募チャネル・応募数・KPI）は
能動応募モデル前提なので、受け身モデルでは丸ごと差し替える。**

> 記事の「とりあえず早く出せ、フィードバックで直せ」は受け身モデルでは成立しない。
> **代替のフィードバック源を自分で用意しないと、プロフィールを改善する材料が永久に入ってこない。**
> → §4-1（スカウトの中身を読む）と §4-2（エージェント面談）がその代替。

### -1-2. プロフィールでは解けない、本当の論点

記事の核心は「**募集要項と一致した経験をどれだけやってきたか**が最重要」。
これを自分に適用すると、不都合な事実に行き当たる。

**社会人経験 約1年5ヶ月（MHD 1年2ヶ月＋SORAMICHI 3ヶ月）。**
エンタメ・IP領域の実務経験は、大学時代の**映画配給会社インターン（数ヶ月・実務担当）**のみ。

> ただし事実確認#2で判明した通り、SORAMICHI 3ヶ月時点で**クライアント窓口と案件リード**を
> 持っている。これは1年5ヶ月のキャリアとしては明確に早い。
> **経験「年数」は短いが、経験の「密度」は主張できる。** ここが v3 で取りこぼしていた反論材料。

エンタメ事業企画の中途採用で競合するのは、典型的には:
- 電通・博報堂の営業／営業企画 5年
- コンサルファーム出身 3〜5年（メディア・エンタメ担当）
- 同業他社からの横移動（業界知識＋人脈あり）

**この差は、LinkedInの書き方では埋まらない。** v2は書類通過率の改善に全ページを割いたが、
仮に書類が完璧でも、経験年数と業界経験のギャップは残る。ここを直視しないと、
「対策したのに通らない → レジュメがまだ悪いのか」と無限に書き直す罠にはまる。

**打ち手は3つ。プロフィール改善はこのうち1つでしかない。**

| 打ち手 | 内容 | 効く時間軸 |
|---|---|---|
| A. 見せ方 | Part 0〜6（この文書） | 即効 |
| B. 標的の選び直し | 大手エンタメ本体だけでなく、**中堅・ベンチャーのエンタメ／D2C／メディアの事業企画・CX**も射程に入れる。「3〜5年」の要件が緩く、π型が刺さる | 即効 |
| C. 経験の作り込み | ~~リード経験を取りに行く~~ → **すでに案件リードとクライアント窓口を持っている**（事実確認#2）。残るは **①数字（定量成果）を取ること ②エンタメ・メディア系クライアントの案件に入ること** | 3〜12ヶ月 |

記事自身も「レジュメに載せられる職歴を作るのに時間がかかる」「足りないと気づいたら
今の会社で補える」と書いている。**Cは記事の指示そのもの。** 見せ方だけに逃げない。

### -1-3. 「3ヶ月で転職?」— スカウト対応の最初の関門

**受け身モデルでも消えない。むしろ最初に来る。** スカウトに返信すると、
最初のカジュアル面談の冒頭5分で必ず聞かれる。

**回答スクリプト（30秒）**
> MHDでは、店頭の仮説とPOSデータを組み合わせた提案で表彰を2回いただきました。
> ただそこで見えたのは、提案の精度は消費者行動をどれだけデータで読めるかで決まる、ということでした。
> それを最短で身につけられる場所としてSORAMICHIを選び、実際に3ヶ月でEC分析基盤の設計まで

謝らない。期間の話をせず、**取りに行ったスキルの話に変換する。**

**受け身モデル特有の利点:** 自分から応募していないので、

これは能動応募より圧倒的に強い。短期在籍の説明責任が構造的に軽くなる。
v3で悩んだ「本命を温存するか」の論点は、応募しない以上そもそも発生しない。

## Part 0. マインドセット（ここが半分）

記事の要点を、浅利俊介の状況に翻訳したもの。**書き方より先にこれ。**

### 0-1. レジュメは職務経歴書ではない。サムネであり広告である

> 履歴書・職務経歴書＝「情報を全て正確に載せる正式書類」
> レジュメ＝「アピールのために取捨選択・装飾された情報媒体」

つまり **不要なこと・都合の悪いことは載せなくていい。順序もアピールしたい順でいい。**
（詐称はダメ。厳選と装飾はOK。）

**あなたの場合の具体的な帰結:**

| これまでの発想 | v2での扱い |
|---|---|
| 職歴を時系列で漏れなく書く | 応募先に刺さる順に並べる。刺さらない経験は削る |
| MHD 1年2ヶ月を説明しないと不誠実 | **説明しない。** 言い訳は書かない（書くほど目立つ） |
| 「〜に携わりました」 | 「〜を転換させた」。主語は自分、動詞は他動詞 |
| 数字がないから曖昧に書く | 数字を取りに行く。無ければ相対表現で断定的に書く |
| 趣味「映画鑑賞 週2本」は私的な話 | **エンタメ応募では立派な資産。** 載せる |

### 0-2. ゴールは「最初のインタビューに呼ばれる」こと。それで120点

オファーではなく、**1本目の面接に呼ばれること**を当面のKPIに置く。
そこに行けて初めてフィードバックが手に入り、面接対策の改善点が見える。
逆に呼ばれない限り、何を直すべきかは永遠にわからない。

→ **面接対策よりレジュメ対策を先にやる。** 英語面接の不安を理由にレジュメを後回しにしない。

### 0-3. 機械（ATS）と人間（5〜10秒）の二正面作戦

企業側は ①ATSで自動フィルタ → ②人が1枚10秒で選別、の2段階で絞る。
だから対策も2つ要る。**この2つは求められるものが違う。**

| | ATS（機械） | 人間（10秒） |
|---|---|---|
| 求めるもの | JDのキーワード一致、機械可読な構造 | 一目でわかる成果、読みやすさ |
| 対策 | JDの語をそのまま使う、単一カラム、標準見出し | 冒頭に成果、数字、太字、1ページ |
| 効く場所 | レジュメPDF、LinkedInの検索ヒット | LinkedInの見出し・写真、レジュメ上3分の1 |

### 0-4. 謙遜とプライドは捨てる

競争相手は「1時間触ったら経験ありと書く」人たち。
一方であなたは**日本人にありがちな過小申告**をしている可能性が高い。

**具体的に捨てるべき謙遜:**
- 「社内表彰2回」を職歴本文に埋めている → **独立した受賞欄に立てる。見出しにも入れる**
- 「営業でした」 → 「LVMH×Diageo合弁の外資酒類メーカーで、競合優位アカウントを転換した」
- 「まだ3ヶ月です」 → 期間は言わない。**やったことを言う**
- コネは使う。リファラルは最強の手段。遠慮する理由がゼロ

### 0-5. 量より質。ただし完璧主義は捨てる

- **Mass Applying はしない。** 質の低い応募を100件送っても弾かれるだけ
- 目標は **応募に対して返信率10%前後**。5%を切ったらレジュメを疑う
- 一方で「完璧になってから応募」は最悪。**まず出す。ただし出す先は選ぶ**（§-1-3: 本命は温存）
- レジュメは生モノ。ちゃんと機能するまで体感1〜3ヶ月、安定するまで半年かかる前提で始める

### 0-6. ブランドは「その地域での知名度」でしか効かない

記事の重要な指摘。あなたの経歴を知名度で分類すると:

| 経歴 | 日本での通り | 外資日本法人 | 海外本社・海外直 |
|---|---|---|---|
| 早稲田大学 国際教養学部 | ◎ | ◯ | **△ 補足が要る** |
| MHD モエ ヘネシー ディアジオ | ◯ | ◎ | **◎ LVMH/Diageoと書けば最強** |
| 株式会社SORAMICHI | △ | △ | **× 会社説明1行が必須** |

→ **打ち手:**
- 早稲田 → 海外向けは `Waseda University (top-tier private university in Japan)` と補足
- MHD → **必ず `Moët Hennessy Diageo (LVMH × Diageo joint venture)` と書く。**
  ここはあなたの経歴で最も国際的に通用する資産。今これを活かしきれていない
- SORAMICHI → 「大手金融・大手小売のCXを支援するコンサルティングファーム」と1行添える

そして最重要は知名度ではなく **募集要項と一致した経験をどう見せるか**。

### 0-7. レジュメ対策はレジュメのためならず

- レジュメに書いた内容は**そのまま面接で深掘りされる** → レジュメ対策＝面接対策の半分
- 職歴をビジネスインパクトで書こうとすると、**普段の仕事で「なぜやるか/どう測るか」を意識するようになる**
- 「リーダーシップ経験が薄い」「インパクトの数字がない」と気づけたら、**今のSORAMICHIで作りに行ける**。
  辞めてから気づくと補う機会がない

### 2-1. 見出し（Headline）— 220文字

### 3-2. JDごとの調整（Mass Applyingをしない代わりにやること）

1. JDから**キーワードを15〜20個**抜く（技術語／ドメイン語／ソフトスキル）
2. Summary（職務要約 3〜4行）に上位5語を入れる
3. 職歴の箇条書きを**JD関連度の高い順に並べ替え**る（§0-1: 順序は自由）
4. JDに刺さらない箇条書きは**削る**（1ページに収める強制力になる）
5. Skills欄をJDの語で置換

→ この作業は `/pdf {会社名}` で自動化できる（job-hunterスキル Task 8）。

### 3-3. 在籍期間の表記（レジュメPDFのみ）

LinkedInと違い、レジュメPDFは**年のみ表記が国際的な標準**。

```
Moët Hennessy Diageo K.K. — Field Sales Representative        2025 – 2026
SORAMICHI Inc. — CX Consultant                                2026 – Present
```

嘘ではなく一般的な表記慣行。§0-1「都合の悪いことは書かなくていい」の正当な適用範囲。

### 3-4. セクション順序

```
1. 氏名 / 連絡先 / LinkedIn URL          ← 本文の一番上に。ヘッダーに入れない
2. Summary（3〜4行）                     ← JDキーワードを詰める
3. Work Experience                       ← 直近から。各社3〜5 bullets
4. Skills                                ← JDの語で構成
5. Education                             ← 早稲田 + 映画配給インターン
6. Awards & Certifications               ← 社内表彰2回 / TOEIC 945 / TOPIK 4
7. Languages
```
新卒でない限り Education は下。**Awards を独立させるのは §0-4 の実装。**

## Part 4. スカウトの運用（応募しない代わりにやること）

### 4-1. KPI — スカウトの「数」ではなく「質」を見る

応募しないので返信率という指標は存在しない。代わりに**受信箱の中身を測る。**

| 見るもの | 意味 | アクション |
|---|---|---|
| **月あたりのスカウト受信数** | プロフィールが検索に乗っているか | ゼロが続く＝検索にかかっていない。§2-1/§2-4のキーワードを疑う |
| **プロフィール閲覧数の推移**（LinkedInが表示） | 検索結果には出ているか | 閲覧はあるがスカウトが来ない＝**見出しとAboutの10秒勝負で負けている** |
| **閲覧者の所属・職種** | 誰に見られているか | エンタメ・外資消費財の人事が混ざっているか。SES・保険ばかりなら設定を絞る |
| **スカウトの職種の中身** | 狙い通りの職種で認識されているか | 「営業」ばかり来る＝データ・CX側の見せ方が弱い。逆も同じ |

**診断の分岐:**
```
スカウトが来ない
├─ プロフィール閲覧数も少ない → 検索にヒットしていない  → スキル・見出しのキーワード（§2-4）
└─ 閲覧数はある              → 10秒で落とされている    → 見出し冒頭40字・About冒頭2行（§2-1/2-2）
```
**これが受け身モデルにおける唯一のフィードバックループ。** 記事の「応募して直す」の代替。

### 4-2. エージェント面談 — 「応募」ではないが情報は取れる

応募しない方針の最大の弱点は、**市場情報とJDが一切入ってこないこと**。
エージェントとの面談は応募ではないので、方針と矛盾せずにこれを埋められる。

- **登録先:** 外資日本法人なら JAC Recruitment / Robert Walters / Michael Page。
  日系エンタメ・メディアなら業界特化のエージェントも
- **取りに行く情報:** 想定年収レンジ、実在する求人のJD、経験年数1年5ヶ月に対する市場の反応、
  「エンタメ事業企画」に必要とされる実際の要件
- **副次効果:** エージェント経由のスカウトも増える
- **注意:** 面談で「今すぐ転職する気はない」と正直に伝えて構わない。
  むしろ長期の関係を作る方が良い案件が回ってくる

### 4-3. リファラルは「応募しない」でも使える

早稲田SILSのOBOGで外資エンタメ・メディア勤務者を探し、**カジュアルに話を聞く**。
これは応募ではないが、
- 社内の実情・組織図・空きポジションの情報が入る
- **相手から「うちに来ませんか」と言われる可能性がある**＝最も質の高いスカウト
- 依頼テンプレは job-hunter スキル Task 3（LinkedIn Outreach）

**受け身モデルにおける最強の一手は、実は §4-3。** アルゴリズム経由より人経由の方が速い。

## Part 5. フィードバックと更新サイクル

### 5-1. 誰に見せるか（ここを間違えると逆効果）

| 見せるべき | 効果が薄い／有害 |
|---|---|
| 応募先領域で**採用した経験がある**人事・マネージャー | 友人、同僚（優しいので通してしまう） |
| **同じ領域の選考を通過した現職者**（外資エンタメ/コンサル勤務のSILS同期など） | 英語ネイティブだが採用経験のない知人 |
| 業界特化のヘッドハンター | 一般的な就活アドバイザー |

AI添削も有効だが、**最終的に人が見るものなので人のフィードバックが一番強い。**
「ここがダメ」と言われる恥を先に払う（§0-4）。

### 5-2. 更新トリガー

レジュメは生モノ。以下のタイミングで**必ず**更新する。

- 案件が1つ終わったとき（成果と数字が新鮮なうちに書く）
- 四半期に1回（何も無ければ「この四半期、書けることが無かった」という警告として受け取る）
- 「リーダーシップの経験が薄い」「数字が出せる仕事がない」と気づいたとき
  → **今のSORAMICHIで取りに行く。** 辞めてから気づくと手遅れ（§0-7）
