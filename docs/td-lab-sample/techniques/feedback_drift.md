# フィードバック・ドリフト

## 何が作れるか
光の点が尾を引きながら外へ流れ、全体がゆっくり渦を巻く。尾の先だけが明るく、根元へ向かって沈む。

## 最小構成

```
noise_seed → level_seed ─┐
                         ├→ comp_mix(add) → level_decay → 出力
        xform_drift ← fb_loop ←┘（level_decay を1フレーム遅れで拾う）
```

5ノード。これ以上削ると成立しない。Feedback TOP が「1フレーム前の自分」を返し、
Transform TOP がそれを少しずらして足し戻す。このズレの蓄積が尾になる。

## 効く3パラメータ

| パラメータ | 上げると | 下げると |
|---|---|---|
| `Decay`（Level TOP の opacity、戻り経路） | 尾が長く伸び、画面が白く飽和していく | 尾が短く切れ、点の集合に戻る |
| `Driftscale`（Transform TOP の scale） | 外向きの流れが速くなり、中心が空く | 流れが止まり、その場に溜まって面になる |
| `Driftrot`（Transform TOP の rotate） | 渦が強く巻き、尾が弧を描く | 尾が直線になり、放射状になる |

## 落とし穴

- **種の移動量が1フレームあたり1〜2pxを超えると、尾が点線に切れる。**
  実際に踏んだ。長い尾が欲しくて種を速く動かすのは逆効果で、正解は `Decay` を上げる方。
  尾を作っているのは種の移動ではなく Transform の蓄積なので、種は「ほぼ止まっている」くらいでいい。
- Transform TOP の extend を繰り返しにすると、外へ流れた絵が反対側から戻ってきて画面が濁る。`zero`（黒で埋める）にする。
- 種が密だと尾が重なって面になり、フィードバックに見えなくなる。Level TOP の黒レベルで疎にしてから流す。

## 組み合わせ相性

- 上流に置くと良いもの: 疎な点を作れるもの全般（Noise + 高い黒レベル / Circle TOP / 輝度キーで抜いた身体シルエット）
- 下流に置くと良いもの: Lookup TOP（尾の輝度差がそのまま色の階調になるので相性が良い）、ブルーム
- 併用すると壊れるもの: 強いブラーを戻り経路に入れると、尾が1周で溶けて消える
